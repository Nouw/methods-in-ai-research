Reference Dialogs
----------------------------------------------------------------------------------------------

This file lists 20 example dialogs.

The exact behavior of your system will depend on your state transition function and response templates, so changes from these dialogs are to be expected. What matters is that the content is correct: the right slots are extracted, the right rules fire, and a restaurant is recommended that fits the requirements.

If you spot any mistakes in this file, send me an e-mail (a.eijpe@uu.nl).

Notation:
  S:  system utterance
  U:  user utterance
